# 🚀 Smart Task & Weather Dashboard

A responsive web application that combines a task management system with real-time weather updates using JavaScript, REST API, and browser storage.

---

## 🔗 Live Project
👉 https://dreamy-cannoli-0e7fe9.netlify.app

---

## 📌 Features
- Add, complete, and delete tasks (CRUD operations)
- Filter tasks (All / Active / Completed)
- Live weather search by city name
- Displays temperature, humidity, wind speed, and condition
- Data saved using localStorage (persists after refresh)
- Fully responsive design (mobile + desktop)

---

## 🛠️ Tech Stack
- HTML5  
- CSS3  
- JavaScript (ES6)  
- Fetch API (Async/Await)  
- LocalStorage  
- Netlify (Deployment)
